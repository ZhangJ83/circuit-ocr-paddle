# 5 分钟 Oral 讲稿（高信息密度）

**[P1]** 各位老师好，我是张健宁，来自中山大学。我的工作是《基于 PaddleOCR-VL 的电路原理图 OCR》，一句话概括：**用 VLM 做电路图文字识别，从零构建数据集，解决模态塌缩，CompF1 从 0 做到 0.3**。代码、数据、权重全部开源。

**[P3]** 问题定义：电路原理图上有元件标号、参数值、引脚号、网络标签，现有 OCR 引擎全部失效。基座 PaddleOCR-VL-0.9B 输入电路图，输出幻觉文本——CompF1 = 0，LineAcc = 0。小数据集微调出现**模态塌缩**：模型不看图片，输出 "1, 2, 3..." 数字序列，输出多样性仅 4%。

**[P4–P5]** 数据集：训练集 1,520 张（KiCad 原理图 1,200 + 合成文字 300 + 真实拍照 20），测试集 150 张纯 KiCad，共 4,810 个 OCR 实例。GT 来自 SVG stroked-text 提取和 PIL draw.text 同步记录，**零 AI 标注，100% 确定性规则生成**。

**[P6]** 7 轮递进式质量验证：JSON Schema → 路径验证 → 控制字符扫描 → 标号正则 → 单位归一化 → KiCad 网表交叉验证 → 10% 人工抽检。质量报告含 12 组 GT-vs-Image 可视化对比。

**[P12]** 场景独特性：与通用 OCR 六维差异——输出结构（自由文本 vs 结构化标号+参数值+引脚）、文字密度（均匀 vs 30+ 实例/页）、文字方向（水平 vs 多向）、符号混合（无 vs 密集电气符号）、领域知识（通用 vs 电子工程 Ω/F/H/V）、评估方式（NED vs CompF1+LineAcc）。

**[P15]** 任务结构：五个隐式子任务共享同一 VLM 解码器——元件检测 → 参数值读取 → 标号-值配对 → 引脚解析 → 网络标号识别。**无显式任务边界，模型需隐式学习多任务协同**。核心指标 CompF1 衡量元件级的标号-值配对正确率。

**[P17]** 实验核心结果。基座模型：CompF1=0, LineAcc=0, NED=0.944。exp6（v1, 300 合成文字 20% 混合）：CompF1=0.119, LineAcc=0.033。**Phase 1（v2, 5,000 合成 KiCad 预训练）：CompF1=0.304, LineAcc=0.040——较 v1 提升 2.6×，较基座从零到可用**。

**[P18–P19]** 模态塌缩根因与解决。四组控制变量实验全部塌缩，**根因定位：解冻 Projector**。Projector（mlp_AR, 25.9M 参数）是视觉→语言的唯一映射桥梁，LoRA 扰动后视觉特征被扭曲为 OOD 向量，LLM 退化为高频 token 机械重复。解决方案：① 冻结 Projector，仅微调 LLM self-attention；② 混入 20% 合成文字数据，强制模型读取图片（合成文字无法通过统计模式猜测）。**CompF1 提升 4.2×（0.028 → 0.126）**。

**[P23]** 规模化合成 KiCad 预训练。Python 脚本随机组合 10 类元件符号，调用 kicad-cli 导出 SVG→PNG，生成 **5,000 张合成原理图**，GT 从 SVG stroked-text 100% 对齐。两阶段策略：5,000 合成预训练 → 1,200 真实微调（LoRA r=16, α=32，冻结 Projector）。

**[P26]** Phase 1 结果。v2 vs v1：CompF1 0.304 vs 0.119（2.6×），LineAcc 0.040 vs 0.033（1.2×）。**JointF1-norm 双方均≈0——标号-参数值配对仍是核心瓶颈**。v2+真实微调退化至 0.002：合成→真实领域迁移不是简单 fine-tune 能解决。

**[P27–P28]** 合成数据有效机制：确定性视觉→文字映射强制模型依赖视觉通路，20% 为最优比（过低防塌缩不足，过高过拟合白底黑字风格）。**该方法具有通用性：任何小数据集 VLM-OCR 任务可复用**。当前瓶颈：1,200 样本不足，ExactMatch=0，复杂样本（ESP32 引脚表）持续塌缩，参数值幻觉未解决。

**[P30–P39]** 定性证据——5 案例三模型对比。案例 0：基座 API 模板 → exp6 数字塌缩 → **Phase 1 前 21 行与 GT 完全一致**。案例 5：exp6 输出 +3.3V×19 行（数值幻觉）→ Phase 1 输出电压+USB+R/C/U 多类型差异化响应。案例 8：exp6 将 AMP POWER 误识为 APP P7016 → **Phase 1 前 13 行完全一致**。

**[P40]** 结论。**有效**：合成数据混合（+4.2×）、冻结 Projector + LoRA、合成 KiCad 预训练（+2.6×）、低 lr + 高 dropout。**无效**：512px 高分辨率、解冻 Projector、更大 LoRA 秩（r=32）、SPICE 格式微调、合成→真实两阶段微调——均未超越 v1 基线。
